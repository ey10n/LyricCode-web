# LyricCode（Web 版）

歌詞の行の上にコードを併記するエディタです。ブラウザで動くので、Windows・Mac・iPad のどれでも同じように使えます。
Windows 版（Lazarus）の機能をそのまま移しています。保存形式（`.lct`）は Windows 版と同じなので、
同じファイルをどちらでも開いて編集できます。

**https://ey10n.github.io/LyricCode-web/** を開くだけで使えます（インストール不要）。
iPad では共有ボタン →「ホーム画面に追加」で、アプリのように起動できます。一度開けば、オフラインでも起動します。

## 使い方

1. 「☰ 曲の一覧」（右上の曲名をタップしても開きます）で曲を選ぶか、「新しい曲」を作ります。
   曲はすべてブラウザの中に自動で保存されます。
2. モード（歌詞 / コード / 歌詞＋コード / 閲覧）を選びます。
3. 歌詞を書くか貼り付けます（iPad はツールバーの「貼り付け」ボタンでも貼れます）。
4. コードを入れたい位置を指して（iPad はタップして）、C～B のキーで基音を入れます。
   右クリック（iPad は長押し）で、基音・コードの種類（m, 7, m7, maj7, dim など）・小節線・音符を選べます。
5. コードの上で右クリック（長押し）すると、コードを点滅させたり色を付けたりできます（この行のコードすべてにも）。
   歌詞の太字は、太字にしたい行にカーソルを置いてツールバーの「B」（Ctrl+B）。
6. ファイルとして残したいときは「ファイル」→「ファイルに保存」（.lct。点滅・色・太字は入りません）。

操作の詳しい説明は、画面の「ヘルプ」→「操作方法」（F1）にあります。

## iPad のアプリ版からの引っ越し

1. iPad のアプリ版で「…」→「Web 版へ書き出す」を押す。全曲（コードの点滅・色、歌詞の太字、プレイリストも）が、
   「ファイル」の「この iPad 内 › LyricCode › Web版へ」に `LyricCode 全曲.json` として書き出されます
2. Web 版で「☰ 曲の一覧」→「取り込む...」を押し、そのファイルを選ぶ
3. 同期（下記）を設定しておくと、取り込んだ全曲が他の端末にも入ります

同じ名前の曲がすでにあるときは、置き換えるか、別の曲として加えるか、飛ばすかを選べます。
`.lct`・`.txt` のファイルも「取り込む...」でまとめて選べます。プレイリストは今は保存だけしています（画面には出ません）。

## 他の端末との同期

右上の「☁ 同期」から、GitHub の非公開の Gist を使って、曲の一覧の全曲を端末どうしで同期できます。
PC で途中まで書いて、iPad で続きを、といった使い方ができます（Lyricker と同じ方式です）。

1. [GitHub のトークン作成画面](https://github.com/settings/tokens/new?scopes=gist&description=LyricCode)で、
   「gist」の権限だけのトークンを作る（**Lyricker で使っているトークンをそのまま使えます**）
2. 同期したい各端末で「☁ 同期」を開き、そのトークンを貼り付けて「保存して同期」
   - Lyricker で同期を設定済みの端末では「Lyricker と同じトークンで同期」を押すだけです

- 編集すると数秒後に自動で送られ、画面を開いたとき・戻ったとき・1 分ごとに他の端末の変更を読み込みます。
- 曲ごとに、あとから編集した方が残ります（別々の曲なら両方の変更が残ります。同じ曲を両方の端末で編集すると、先に編集した方の変更は消えます）。
- 削除した曲は、他の端末からも消えます。
- 同期の画面に「同期先 Gist」の番号が出ます。端末どうしで同じ番号なら、同じ所に同期しています。
- 同期先は Lyricker とは別の Gist（`lyriccode-sync.json` を持つもの）です。

### データの置き場所

曲の一覧（全曲）・設定・同期用のトークンは、その端末のブラウザの中（localStorage）に保存されます。
同期を使うと、全曲が、あなたの GitHub アカウントの非公開の Gist にも置かれます。
ブラウザの「履歴とデータを消去」をすると曲も消えるので、同期を使うか、ときどきファイルに保存してください。

## Windows 版との違い

| 項目 | Windows 版 | Web 版 |
|---|---|---|
| 使い始め | インストール | URL を開くだけ |
| 他の端末との同期 | なし | GitHub の Gist で同期 |
| PDF の読み込み | Poppler の pdftotext が必要 | 不要（PDF.js を使用。iPad でも使える） |
| 保存 | 上書き保存 | Chrome・Edge は上書き保存、Safari はダウンロードとして保存 |
| 曲の管理 | ファイルごと | 曲の一覧（ブラウザに自動で保存。同期もできる） |
| コードの点滅・色、歌詞の太字 | なし | あり（.lct には入らない） |
| 自由文字入力 | Ctrl+T | Ctrl+Shift+F（ツールバーの「自由文字」ボタンでも可） |
| モード切替 | Ctrl+1～4 | Alt+1～4 |
| 新規 | Ctrl+N | Alt+N |
| 全体をテキストとしてコピー | Ctrl+Shift+C | Ctrl+Shift+E |

Ctrl+N・Ctrl+T・Ctrl+1～4・Ctrl+Shift+C はブラウザが使っているため、Web 版では別のキーにしています。

## 開発

ビルド作業は不要です。ファイルをそのまま Web サーバーに置けば動きます
（GitHub Pages ならリポジトリの設定で公開するだけ）。
`index.html` をダブルクリックしても動きますが、オフライン起動の仕組みは `https://` か `http://localhost` のときだけ働きます。

**公開し直すときは、`sw.js` の `CACHE` と `js/app.js` の `APP_VERSION` を同じ番号に上げてください**
（上げないと、iPad などに保存された古いファイルが使われ続けることがあります）。

| ファイル | 役割 |
|---|---|
| `index.html` / `css/style.css` | 画面 |
| `js/app.js` | メニュー・曲の一覧の画面・取り込み・ファイル操作・ショートカット・同期の画面 |
| `js/library.js` | 曲の一覧（全曲をブラウザに保存。同期のときに曲ごとに新しい方を残す） |
| `js/editor.js` | エディタ本体（描画・マウス・キーボード・日本語入力） |
| `js/chord.js` | コード名の解析・移調・コード行の判定 |
| `js/sheet.js` | 文書のデータと `.lct` 形式の読み書き、点滅・色・太字（飾り）の読み書き |
| `js/text.js` | 文字の幅・文字コードの判定・文字化けの修復 |
| `js/ui.js` | メニューとダイアログ |
| `js/pdfimport.js` | PDF のコード譜の取り込み（PDF.js を jsDelivr から読み込む） |
| `js/cloud.js` | 他の端末との同期（GitHub の Gist） |
| `sw.js`・`manifest.webmanifest`・`icons/` | ホーム画面への追加とオフライン起動 |
